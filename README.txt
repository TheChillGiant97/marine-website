START HERE

1. Install Visual Studio Code: https://code.visualstudio.com/
2. Unzip this folder.
3. In VS Code: File > Open Folder > choose marine_website_starter.
4. Install the VS Code extension "Live Server" by Ritwick Dey.
5. Open index.html, right-click and choose "Open with Live Server".
6. Your website opens locally in the browser.

To add a hero photo:
- save it as assets/images/hero.jpg

To add a hero video later:
- save a short compressed MP4 as assets/video/hero.mp4
- in index.html change:
  class="hero-video hidden-media"
  to:
  class="hero-video"

"MARINE PROJECT" and hello@example.com are placeholders until the final name/email exist.
No domain or hosting is needed yet.
